# Guías de implementación por tandas

Ejecutar en orden y registrar evidencia en [avances](../avances.md). Cada guía contiene objetivo, tickets, aceptación y demostración. Las reglas transversales de [deporte](../06-reglas-deportivas.md), [seguridad](../07-permisos-y-seguridad.md), [visual](../10-guia-visual.md) y [calidad](../11-operacion-y-calidad.md) aplican en todas.

**Total vigente: nueve tandas.** El diseño y su revisión se incluyen desde T01 y continúan en cada entrega; las observaciones del gym están incorporadas a la guía visual. No existe una tanda adicional de rediseño planificada.

| Tanda | Resultado |
|---|---|
| [01 — Cimientos](01-cimientos.md) | Entornos, cuentas, organizaciones, permisos, respaldo. |
| [02 — Torneos y reglas](02-torneos-reglas.md) | Ediciones, equipos, administradores de equipo, comisión y reglamentos. |
| [03 — Jugadores y planillas](03-jugadores-planillas.md) | Buena fe, ficha, origen interno/externo, elegibilidad y convocatoria móvil. |
| [04 — Fixture y jornadas](04-fixture-jornadas.md) | Programación por horario/cancha, cuadros y publicación. |
| [05 — Resultados y actas](05-partido-en-vivo.md) | Carga posterior continua de goles/tarjetas, acta oficial y corrección; vivo secundario. |
| [06 — Estadísticas y disciplina](06-estadisticas-disciplina.md) | Tabla, goleadores, sanciones y multas coherentes. |
| [07 — Control y exportaciones](07-control-y-exportaciones.md) | Bandeja, comisión, multas deportivas y documentos privados. |
| [08 — Flyers y portal](08-flyers-portal.md) | Exportación local y consulta pública completa. |
| [09 — Piloto y lanzamiento](09-piloto-lanzamiento.md) | Rendimiento, recuperación, seguridad y prueba real. |

Un ticket `Txx-nn` está preparado cuando sus datos, permiso, UI, API, errores y prueba son concretos. Está aceptado cuando hay demostración y evidencia. No cambiar el estado por haber escrito esta guía.

La antigua [T07 de finanzas](07-finanzas.md) se conserva solo como antecedente y no debe implementarse.
