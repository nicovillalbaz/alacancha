# T05-01a — captura privada de partido

**Fecha:** 29/10/2026. **Estado:** primer incremento vertical de T05 en código local; acta oficial, operadores asignados y difusión permanecen pendientes.

| Aspecto | Evidencia |
|---|---|
| Datos y migración | Migraciones 017/018: registro por partido con versión de reglamento y dos planillas aprobadas congeladas; diario de eventos con secuencia e identidad de solicitud únicas, inmutable en base. La 018 amplía períodos hasta seis, según el reglamento ya vigente. No se reescribieron partidos ni planillas anteriores. Respaldo cifrado previo a cada migración y restauración ensayada en base nueva; última comprobación: 100 archivos y filas/huellas iguales. |
| API | El organizador abre la carga solo para un partido de Fecha publicada con ambas últimas planillas aprobadas. Puede registrar gol, penal, autogol, amarilla y roja, con jugador de esa planilla, período y minuto opcionales; las tarjetas exigen jugador y reglamento habilitante. El marcador se deriva del diario; autogol suma al rival. Reintentar la misma identidad de evento devuelve el estado existente. Deshacer agrega una corrección motivada; conserva el original. |
| UI | En Fixture publicado aparece **Completar partido**. La pantalla móvil mantiene equipo, período y tipo al tocar jugadores consecutivos, sin desplegables; equipos con escudo o marca de color, PT/ST/TE y períodos adicionales visibles, marcador privado, historial y deshacer. Las capturas [selección a 390 px](t05-captura-390.png) y [jugadores/deshacer](t05-captura-jugadores-390.png) usan datos sintéticos temporales solo para revisión visual; la rama de prueba fue retirada del código final. |
| Permisos | Lectura y escritura solo para administrador de torneo activo en la organización del partido. Otra organización, administrador de equipo y superadmin sin rol de organizador reciben 403; no se acepta `organization_id` del cuerpo como autorización. El diario y los nombres de planilla permanecen privados. |
| Vacío y error | Sin registro se ofrece abrir la carga. Partido inexistente, Fecha privada, planillas ausentes, jugador fuera de planilla, período no previsto, tarjeta no permitida y reuso contradictorio de identidad devuelven errores explícitos. Guardar una nueva versión de planilla o reprogramar el partido se bloquea tras abrir el registro. |
| Pruebas | `npm test`: **53/53**. Incluye acceso permitido/denegado, precondiciones, congelación, gol/tarjeta/autogol, minuto nulo, reintento, corrección y diario inmutable. `npm run typecheck` y `npm run build` aprobados. Revisión visual sintética en 320, 390, 768 y 1280 px sin desbordamiento ni controles visibles bajo 44 px; selección de ST con teclado y nombres largos. |
