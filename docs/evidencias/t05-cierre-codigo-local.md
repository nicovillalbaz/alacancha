**Flujo demostrado:** dos planillas aprobadas → carga privada → envío provisional → conformidades o excepción motivada → resultado oficial → rectificación y nueva aprobación. La API pública devuelve solo marcador, tanda y estado; no filtra cédula, fecha de nacimiento, documentos, identificadores de registro ni eventos privados. T06 toma las actas aprobadas para clasificación, goleadores, tarjetas y disciplina; T04 aún debe usar esos resultados para avanzar ganadores y clasificados.

**Riesgo operativo:** IndexedDB depende del almacenamiento disponible en el dispositivo. Antes de cerrar la app o cambiar de cuenta, el planillero debe verificar “sincronizado”; el botón de enviar acta queda deshabilitado mientras esta pantalla conoce eventos pendientes. Un corte de red después de que el servidor guarde un evento se resuelve reenviando su mismo `clientEventId`. La nota libre de una incidencia puede permanecer en el almacenamiento local hasta sincronizar o cerrar sesión; conviene evitar datos personales innecesarios en ese campo.
