# Alta rápida de jugador en nómina y acta — 16/11/2026

## Alcance

- Alta ordinaria de jugador con solo nombres y apellidos. Documento, fecha de nacimiento, número de ficha, procedencia y datos de ficha se pueden completar después.
- Durante la captura del partido, el organizador puede crear con nombres y apellidos a un jugador del equipo elegido y atribuirle inmediatamente la acción que está cargando. El alta queda en borrador privado; no aprueba la buena fe ni publica por sí sola la identidad.
- Si el torneo configura un rango de edad y falta la fecha de nacimiento, la evaluación muestra que falta el dato para verificarlo. El alta rápida no inventa una edad.

## Datos y migración

- `054_match_quick_players.sql` permite `players.birth_date` nulo. Es una migración aditiva; no elimina ni reescribe fechas existentes.
- El alta durante el acta crea `players` y `player_registrations`, añade la inscripción a la nómina congelada y guarda el evento oficial en **una sola transacción**. Conserva el identificador de inscripción enviado por el cliente como identificador del evento para que un reintento no duplique jugador ni evento. Un evento inválido revierte también el alta.
- No se ejecutó esta migración en producción en este incremento.

## API, permisos y estados

- `POST /api/v1/organizations/:id/matches/:matchId/record/players` requiere administrador activo de la organización del partido. Comprueba el equipo, estado de captura, ausencia de planilla aprobada para ese equipo y cupo configurado. Rechaza acceso entre organizaciones y datos de otro equipo.
- Devuelve 201 al crear y 200 si recibe el mismo identificador, datos y evento. Un identificador reutilizado con otros datos o evento responde conflicto.
- Si no hay acta abierta, si el acta está cerrada, si existe una planilla aprobada o si se llenó el cupo, devuelve un error explícito. El selector del acta ofrece el alta rápida solo cuando la acción es posible.
- La pantalla y la API de alta ordinaria permiten guardar con solo nombres y apellidos; los datos adicionales quedan en una sección opcional. El importador CSV también admite nacimiento vacío.
